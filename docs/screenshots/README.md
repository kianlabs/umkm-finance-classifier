# Screenshot Aplikasi

Folder ini tempat screenshot untuk README utama. File yang diharapkan:

| File | Isi |
|---|---|
| `dashboard.png` | Halaman Dashboard / Beranda (hero + kartu metrik model) |
| `klasifikasi.png` | Halaman Klasifikasi dengan hasil prediksi 4 kelas + probabilitas per kelas |
| `visualisasi.png` | Halaman Visualisasi (confusion matrix / ROC OvR) |

Cara mengambil: jalankan `python app.py` di folder `umkm-financial-classifier/`,
buka http://localhost:5000, lalu screenshot tiap halaman (disarankan lebar ±1280px).
